# Reproducibility

## 1. Environments

```bash
# Main modeling environment
conda env create -f environment.yml
conda activate egfr-aidd

# Docking environment (rdkit + meeko + openbabel)
conda env create -f environment-docking.yml
conda activate egfr-aidd-dock
```

`environment.yml` pins the exact versions used for the frozen results
(Python 3.10.20, scikit-learn 1.7.2, RDKit 2026.03.5, PyTorch 2.13.0,
PyTorch Geometric 2.8.0.post1, XGBoost 3.2.0, and the remaining package
versions recorded in the result JSON files).

AutoDock Vina 1.2.x is not redistributed; install it separately and make it
available on PATH or pass `--vina-bin`.

## 2. Committed Data

The final curated dataset is committed at
`data/processed/egfr_activity_final.csv`. Raw ChEMBL downloads and
preprocessing intermediates are not committed; regenerate them with:

```bash
python src/data/download_chembl.py    # needs internet (ChEMBL)
python src/data/preprocess_egfr.py
```

Docking needs only `data/docking/1M17.pdb`,
`data/docking/1m17_receptor.pdbqt`, and `data/docking/vina_box.json`;
ligand PDBQTs are regenerated by the docking script.

## 3. Reproduce the Headline Results

From the project root, with the `egfr-aidd` environment active:

```bash
python src/models/final_rf_confirmation.py
python src/models/final_known_inhibitor_check.py
python src/models/final_candidate_prioritization.py   # runs 25 frozen-model fits
python src/models/m9_retrospective_benchmark.py
python src/models/p03_multiseed_reproducibility.py
```

With the `egfr-aidd-dock` environment active and Vina installed:

```bash
python src/models/m7_docking.py --top-n 20
python src/models/m9_docking_pose_validation.py
```

The final candidate scripts consume compact candidate-level input tables
that are committed under `results/` (for example
`results/m65_improved_shortlist.csv`, `results/m7_admet_descriptors.csv`,
`results/m7_docking_results.csv`, and `results/m8_final_candidates.csv`),
so the final shortlist can be regenerated without rerunning every earlier
experiment.

## 5. Fixed Randomization

* Split seed: 42 (standard scaffold split).
* Model random_state: 42 (locked Morgan-RF).
* Multi-seed audit: {42, 7, 123, 2024, 777}.
* Bootstrap seed: 42; docking seed: 42.

## 6. What Is Not Committed

* `data/raw/` and `data/interim/`: regenerable via the download/preprocess
  scripts.
* `results/models/`: trained model artifacts; regenerated by the scripts.
* `data/docking/vina`: platform-specific AutoDock Vina binary.
* Raw 25-run stability tables and per-molecule prediction tables: replaced
  by compact final summaries in `results/`.

Result JSON files record package versions, split indices, and model
parameters so frozen numbers remain auditable.
